# Processed project data

These files are the reproducible, app-ready outputs of `Topic47_Colab_GPU_Executed.ipynb`. They are intentionally included so a fresh clone can run the dashboard without downloading the 226 MB raw PBF.

Do not add raw `.osm.pbf` or `.geojsonseq` intermediates to Git. To regenerate these artifacts, use the notebook and source data from [Geofabrik Kazakhstan](https://download.geofabrik.de/asia/kazakhstan.html).

Data attribution: © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright); extract by Geofabrik. Population data is from the [Kazakhstan Bureau of National Statistics](https://stat.gov.kz/en/region/), snapshot 2026-10-01.
